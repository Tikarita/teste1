# AktIA

Plataforma de controle de qualidade de radiografias odontológicas: classificação de
qualidade, pré-laudo e registros para o Programa de Garantia da Qualidade.

Este Space roda o site e a API juntos. O código vem do repositório
https://github.com/Tikarita/teste1 (pastas `aktia-frontend` e `aktia-backend`).

Segredos necessários no Space: `SUPABASE_URL` e `SUPABASE_KEY` (chave `service_role`).
